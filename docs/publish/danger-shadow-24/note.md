# 你体内最危险的那一面，藏得有多深？

你是不是也这样？

平时脾气很好，
别人临时改计划，你说“没事”；
功劳被抢，你先顾全场面；
关系里受了委屈，也习惯自己消化。

可真的被踩到底线以后，
你会像突然换了一个人。

有人开始控制所有细节，
因为只要局面还在手里，就不会再次受伤。

有人当场反击，
不是天生暴躁，而是之前已经忍了太久。

有人突然冷下来，
一句解释都不想听，心里已经完成关系降级。

还有人表面照常相处，
却把每一次失信、缺席和不公平都记得很清楚。

你以为那是“性格变差了”，
其实很多时候，
那是你被逼到墙角时自动启动的保护程序。

我把这种很难承认、却真实存在的反应，
写成了24个具体情境。

不是问你“应该怎么做”，
而是看：

被当众冒犯时，你先反击、观察还是抽离；
关系突然失控时，你会追问、降级还是记账；
利益被抢时，你更想拿回规则、证明自己还是等待清算；
当你拥有主动权时，会怎样使用自己的力量。

最后会生成一份专属暗面档案：
主要暗面保护人格
第二倾向与六维雷达
最容易触发你的场景
保护动作背后的真实需要
最可能误伤关系的地方
适用边界与30天降温练习

没有好坏，也不是心理诊断。
危险的从来不是有暗面，
而是你不知道它什么时候会替你做决定。

答题时别选最体面的，
选那个最像你真实第一反应的答案。
