# 你以为自己很独立，可能只是不敢麻烦别人

你是不是也这样？

遇到困难，第一反应永远是“我自己来”。
别人问你需不需要帮忙，嘴上说不用，
心里却有一点希望 ta 再问一次。

受了委屈，你先把情绪收好；
重要决定，你不想让任何人干涉；
关系真的变近时，你又会下意识后退。

别人看到的是懂事、能扛、有主见。
只有你知道：
有时候你不是不需要，
只是太怕开口以后没有人接住。

我把“独立”拆成了4个维度：
自主决策、求助弹性、情绪自持、独处舒适。

24道生活情境，不问你“应不应该独立”，
只看你面对求助、亲密、冲突和失控时，
最真实的第一反应。

结果可能是：
真独立·稳定自主型
假独立·铠甲硬撑型
半独立·关系借力型
摇摆独立·情境切换型

真正的独立不是谁都不需要，
而是你既能一个人站稳，
也敢在需要时让可靠的人靠近。

测试仅作趣味自我观察，不构成心理诊断。
